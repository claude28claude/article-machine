@lesson 2.1 | Variables | 25
@goal Create variables, change them, and choose names that make code readable.

So far every value was typed straight into `print()`. Real programs need to **remember** values: a score, a name, a total. A **variable** is a name that points at a value.

```py
exam = "SSC CGL"
year = 2026
print(exam, year)
```

Read `=` as "store" or "now refers to", **not** "equals". `year = 2026` means: make the name `year` point at the value `2026`. From then on, writing `year` anywhere means 2026.

## Variables can change

That's why they're called variables. A new assignment makes the name point at a new value; the old value is forgotten.

```py
score = 120
print(score)
score = 145
print(score)
```

Python always works out the right side of `=` first, then stores the result in the name on the left. So this is perfectly normal Python:

```py
count = 10
count = count + 5
print(count)
```

Line 2 means: take the current `count` (10), add 5, and store the result (15) back in `count`. Press **Step through** on that example and watch the value change in the variables table.

## Shortcuts for updating

Updating a variable is so common that Python has short forms:

```py
xp = 100
xp += 20   # same as xp = xp + 20
xp -= 5    # same as xp = xp - 5
xp *= 2    # same as xp = xp * 2
print(xp)
```

## Naming rules

- Names use letters, digits and underscores, and **can't start with a digit**: `mark1` works, `1mark` doesn't.
- Names are **case-sensitive**: `Score` and `score` are two different variables.
- Python's own words (`for`, `if`, `class`, `print`...) shouldn't be used as names.
- By convention Python uses **snake_case**: lowercase words joined by underscores, like `total_marks` or `days_left`.

Good names make code read like English. Compare `x = 87` with `english_marks = 87`. Six months from now you'll thank yourself.

```py error
1st_place = "Riya"
```

A: Assignment: work out the value on the right, then make the name on the left point at it. It is not "equals" in the maths sense.
Q: What does `x += 3` do?
A: It adds 3 to x and stores the result back in x. It is short for `x = x + 3`.

@lesson 2.2 | Numbers and maths | 25
@goal Calculate with whole and decimal numbers, use `//`, `%` and `**`, and control the order of operations.

Python has two main kinds of number:

- **int** (integer): a whole number like `7`, `-3` or `2026`.
- **float**: a number with a decimal point like `7.5`, `0.25` or `-1.0`.

```py
marks = 145
average = 72.5
print(type(marks))
print(type(average))
```

`type()` tells you what kind of value something is. You'll use it a lot when debugging.

## The operators

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| `+` | add | `7 + 2` | `9` |
| `-` | subtract | `7 - 2` | `5` |
| `*` | multiply | `7 * 2` | `14` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | floor divide (whole part) | `7 // 2` | `3` |
| `%` | remainder (modulo) | `7 % 2` | `1` |
| `**` | power | `7 ** 2` | `49` |

```py
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
```

`/` always gives a float, even when the answer is whole: `10 / 2` is `5.0`.

## // and % are a team

`//` tells you how many whole times something fits; `%` tells you what's left over. Together they convert units:

```py
total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(hours, "hours", minutes, "minutes")
```

`%` is also the standard way to test whether a number is even: `n % 2` is 0 for even numbers and 1 for odd ones.

## Order of operations

Python follows the same order as school maths (BODMAS): brackets first, then powers, then `*` `/` `//` `%`, then `+` `-`. When in doubt, add brackets. They make your intention clear to readers too.

```py
print(2 + 3 * 4)
print((2 + 3) * 4)
```

## Rounding

`round(x, n)` rounds to `n` decimal places. `abs(x)` gives the distance from zero.

```py
print(round(72.3456, 2))
print(round(7.5))
print(abs(-12))
```

:::warn
Floats are stored in binary, so some decimals can't be exact: `0.1 + 0.2` gives `0.30000000000000004`. This happens in every programming language. Use `round()` when you display money or marks.
:::

```py
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
```

:::real
SSC CGL Tier 1 gives **2 marks** for a correct answer and takes away **0.5** for a wrong one. That's one line of Python: `score = correct * 2 - wrong * 0.5`. Because 0.5 is a float, the score comes out as a float too.
:::

:::recall
Q: What is the difference between `/` and `//`?
A: `/` is normal division and always gives a float (`7 / 2` is `3.5`). `//` is floor division and keeps only the whole part (`7 // 2` is `3`).
Q: What does `%` do?
A: It gives the remainder after division. `17 % 5` is `2`. `n % 2 == 0` means n is even.
Q: What does `**` do?

@lesson 2.3 | Text and types | 25
@goal Join and repeat text, measure it with `len()`, and convert between text and numbers on purpose.

Text values are called **strings** (type `str`). You can build strings from other strings:

```py
first = "Sachin"
last = "Tendulkar"
print(first + " " + last)
print("=" * 20)
print(len("Constitution"))
```

- `+` joins (concatenates) strings.
- `*` repeats a string.
- `len()` counts the characters, spaces included.

## Text and numbers don't mix automatically

`"5"` (a string) and `5` (an int) look alike but are different types. Python refuses to guess what you mean when you combine them:

```py error
age = 25
print("Age: " + age)
```

That's a `TypeError`: you can only `+` a string to another string. You have three fixes, and each is useful:

```py
age = 25
print("Age: " + str(age))   # convert the number to text
print("Age:", age)           # let print() join them with a space
```

## Converting on purpose

| Function | Turns into | Example |
| --- | --- | --- |
| `str(x)` | text | `str(25)` is `"25"` |
| `int(x)` | whole number | `int("42")` is `42`, `int(7.9)` is `7` |
| `float(x)` | decimal number | `float("3.5")` is `3.5` |

```py
a = "10"
b = "20"
print(a + b)
print(int(a) + int(b))
```

The first line joins two pieces of text; the second adds two numbers. Same characters, completely different meaning: that's why types matter.

`int()` fails if the text isn't a whole number. Remember this error; you'll meet it with user input:

```py error
int("twelve")
```

:::tip
When something behaves strangely, print its type: `print(type(x))`. Half of all beginner bugs are a number that is secretly a string.
:::

:::predict
```py
print("3" * 3)
print(3 * 3)
```
- 9\n9
+ 333\n9
- 333\n333
- 9\n333
= A string times a number repeats the string. A number times a number is multiplication.
:::

:::quiz
? What is `len("SSC CGL")`?
- 6
+ 7
- 3
- 2
= `len()` counts every character, including the space in the middle: S, S, C, space, C, G, L.
:::

:::recall
Q: Why does `"Age: " + 25` fail?
A: `+` can't join a string and an int. Convert first with `str(25)`, or pass both to `print()` separated by a comma.
Q: What do `int()`, `float()` and `str()` do?
A: They convert a value: to a whole number, to a decimal number, or to text.
Q: What does `len()` return for a string?
A: The number of characters in it, including spaces.
:::

@lesson 2.4 | Input from the keyboard | 25
@goal Read what the user types with `input()`, convert it, and build small interactive programs.

`input()` pauses the program, waits for the user to type something and press Enter, and gives you what they typed **as a string**.

```py
name = input("What is your name? ")
print("Welcome,", name)
```

```stdin
Aman
```

Run it in the bench: a box appears under the output where you type your answer. The text inside the brackets is the **prompt**, shown before the user types. End it with a space so the answer doesn't stick to it.

## input() always gives you text

This is the number one input bug. Even if the user types `25`, you get the string `"25"`:

```py error
age = input("Age: ")
print(age + 1)
```

```stdin
25
```

Convert it straight away when you need a number:

```py
age = int(input("Age: "))
print("Next year you will be", age + 1)
```

```stdin
25
```

`int(input(...))` reads from the inside out: `input()` runs first and returns text, then `int()` turns that text into a number. Use `float(input(...))` for decimals like a percentage.

## A complete small program

Most programs follow the same shape: **input, process, output**.

```py
# input
correct = int(input("Correct answers: "))
wrong = int(input("Wrong answers: "))
# process
score = correct * 2 - wrong * 0.5
# output
print("Your score is", score)
```

```stdin
70
10
```

:::warn
If the user types `twelve` where your program does `int(input())`, the program crashes with a ValueError. In Unit 9 you'll learn to catch that and ask again politely.
:::

:::quiz
? The user types `7` at `x = input()`. What is `x`?
- The int 7
+ The string "7"
- The float 7.0
- Nothing until you convert it
= `input()` always returns a string. Convert it with `int()` or `float()` before doing maths.
:::

:::recall
Q: What type of value does `input()` return?
A: Always a string, even if the user types digits.
Q: How do you read a whole number from the user?
A: Wrap the input in int(): `n = int(input("Number: "))`.
Q: What three steps do most simple programs follow?
A: Input, process, output: read the data, calculate, then print the result.

@lesson 2.5 | Project: Mock test score card | 40 | project
@goal Combine variables, maths, conversion and input into one complete, useful program.

Time to build something you could actually use. A **score card** for an SSC CGL Tier 1 mock test: 100 questions, 2 marks for each right answer, 0.5 taken away for each wrong one, nothing for questions left blank.

Here is what the finished program does when the user types `Aman`, `72` and `18`:

```text
Name: Aman
Correct answers: 72
Wrong answers: 18
========================================
MOCK TEST SCORE CARD: AMAN
Attempted: 90 of 100
Score: 135.0 out of 200
Accuracy: 80.0 percent
Left blank: 10
========================================
```

The first three lines are the prompts and the user's answers; your program prints the rest.

## Plan before you type

Professional programmers sketch the steps first. Here they are:

1. **Input**: read the name, the number correct, and the number wrong.
2. **Process**:
   - attempted = correct + wrong
   - score = correct times 2, minus wrong times 0.5
   - accuracy = correct divided by attempted, times 100, rounded to 1 decimal place
   - blank = 100 minus attempted
3. **Output**: print the card. `name.upper()` gives the name in capitals; you'll learn more tricks like that in Unit 3.

Build it **one step at a time**: write the input lines, run, then add one calculation, run, and so on. Running often means each new bug is in the line you just wrote.

:::tip
Stuck on a step? Press **Step through** to watch every variable. Or ask the tutor about your code: it gives hints, not answers.
:::

:::recall
Q: What should you do before writing a program?
A: Plan the steps: what goes in, what you calculate, and what comes out.
Q: Why run your code after every few lines?
A: So when something breaks, the bug is almost certainly in the lines you just added.
:::
