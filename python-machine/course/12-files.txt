@lesson 12.1 | Reading and writing files | 25
@goal Open files with `with`, read them line by line, write and append text, and handle missing files.

Everything so far vanished when the program ended. **Files** let data outlive the program: notes, logs, results, settings.

This lesson comes with a file called `notes.txt` in your workspace:

```file notes.txt
Article 14: Equality before law
Article 19: Freedom of speech, etc
Article 21: Protection of life and personal liberty
Article 32: Remedies for enforcement of rights
```

## Reading

```py
with open("notes.txt", encoding="utf-8") as f:
    text = f.read()
print(text)
print(len(text), "characters")
```

`open()` gives you a file object; `with` makes sure the file is **closed** when the block ends, even if an error happens. Always use `with` for files.

`encoding="utf-8"` tells Python how the characters are stored. Include it: it makes files with Hindi or symbols like ₹ read correctly on every computer.

## Line by line

Looping over a file gives one line at a time, which works even for files too big to fit in memory:

```py
with open("notes.txt", encoding="utf-8") as f:
    for number, line in enumerate(f, start=1):
        print(number, line.strip())
```

Each line still ends with `\n`, so `strip()` it before using it.

## Writing and appending

The second argument to `open()` is the **mode**:

| Mode | Meaning |
| --- | --- |
| `"r"` | read (the default) |
| `"w"` | write: creates the file, or **erases** it if it exists |
| `"a"` | append: adds to the end |

```py
with open("log.txt", "w", encoding="utf-8") as f:
    f.write("Day 1: print and variables\n")
    f.write("Day 2: strings\n")

with open("log.txt", "a", encoding="utf-8") as f:
    f.write("Day 3: decisions\n")

with open("log.txt", encoding="utf-8") as f:
    print(f.read())
```

`write()` doesn't add new lines for you: include `\n` yourself.

:::warn
`"w"` silently erases an existing file. When you mean "add to it", use `"a"`.
:::

## Missing files

```py error
with open("missing.txt", encoding="utf-8") as f:

```

Check first with `os.path.exists()`, or catch `FileNotFoundError`:

```py
import os

    print(name, "doesn't exist yet")
```

```py
with open("t.txt", "w", encoding="utf-8") as f:

```

:::

:::recall
Q: Why open files with a `with` statement?
A: It closes the file automatically when the block ends, even if an error happens.
Q: What is the difference between modes "w" and "a"?
A: "w" creates or erases the file before writing; "a" adds to the end of it.
Q: Why call strip() on lines read from a file?
A: Each line ends with a newline character, which strip() removes.
:::

@lesson 12.2 | CSV files | 25
@goal Read and write CSV files, the format every spreadsheet can open, with the `csv` module.

**CSV** (comma-separated values) is plain text where each line is a row and commas separate the columns. Excel, Google Sheets and nearly every data tool can open and save it. This lesson's file:

```file marks.csv
name,polity,history,economy
Aman,42,38,45
Riya,47,44,39
Dev,35,41,36
Sana,44,46,48
```

The first row is the **header**: the column names.

## Reading with csv.reader

```py
import csv

with open("marks.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)       # take the first row
    print(header)
    for row in reader:
        print(row)
```

Each row is a list of **strings**: `'42'`, not `42`. Convert numbers with `int()` before doing maths. `newline=""` is what the csv module wants when opening the file; just include it.

## Reading with csv.DictReader

`DictReader` uses the header to turn each row into a dictionary, so you can use column names instead of positions:

```py
import csv

with open("marks.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        total = int(row["polity"]) + int(row["history"]) + int(row["economy"])
        print(row["name"], total)
```

Code that says `row["history"]` keeps working even if someone adds a column, and it's far easier to read than `row[2]`.

## Writing CSV

```py
import csv

rows = [["name", "total"], ["Aman", 125], ["Riya", 130]]
with open("totals.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(rows)

with open("totals.csv", encoding="utf-8") as f:
    print(f.read())
```

Why not just `split(",")`? Real CSV files contain values like `"Remedies for enforcement of rights, etc"` with commas **inside** quotes. The csv module handles those correctly; a plain split breaks them.

:::predict
```py
import csv
import io
row = next(csv.reader(io.StringIO('14,"Equality, before law"')))
print(len(row), row[1])
```
- 3 Equality
+ 2 Equality, before law
- 2 "Equality, before law"
- 3 before law
= The quotes tell csv that the comma inside belongs to the value, so there are 2 columns and the quotes themselves are removed.
:::

:::recall
Q: What type are the values csv.reader gives you?
A: Strings. Convert numbers with int() or float() before maths.
Q: What does csv.DictReader do?
A: Reads each row as a dictionary keyed by the header names, so you can write row["name"].
Q: Why use the csv module instead of split(",")?
A: It handles quoted values that contain commas, and other edge cases, correctly.
:::

@lesson 12.3 | JSON | 25
@goal Save and load structured data (dictionaries and lists, nested any way) with the `json` module.

CSV is great for tables. For anything with structure (records inside records, lists of tags, settings) the standard is **JSON** (JavaScript Object Notation). It looks almost exactly like Python dictionaries and lists:

```file articles.json
[
  {"a": "14", "h": "Equality before law", "p": "III"},
  {"a": "21", "h": "Protection of life and personal liberty", "p": "III"},
  {"a": "44", "h": "Uniform civil code for the citizens", "p": "IV"},
  {"a": "280", "h": "Finance Commission", "p": "XII"},
  {"a": "352", "h": "Proclamation of Emergency", "p": "XVIII"}
]
```

Fun fact: this is the same shape as the data behind your Article Machine (`a` for article, `h` for heading, `p` for Part).

## Loading

```py
import json

with open("articles.json", encoding="utf-8") as f:
    articles = json.load(f)
print(type(articles), len(articles))
print(articles[0]["h"])
for art in articles:
    print(art["a"], "is in Part", art["p"])
```

`json.load(f)` reads a file; `json.loads(text)` reads a string.

## Saving

```py
import json

progress = {"name": "Aman", "lessons_done": 42, "streak": 9, "weak": ["recursion", "CSV"]}
with open("progress.json", "w", encoding="utf-8") as f:
    json.dump(progress, f, indent=2)

with open("progress.json", encoding="utf-8") as f:
    print(f.read())
```

`indent=2` makes the file readable for humans. `json.dumps(data)` gives the JSON as a string instead of writing a file.

## How the types map

| JSON | Python |
| --- | --- |
| object `{...}` | dict |
| array `[...]` | list |
| string `"..."` | str |
| number | int or float |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

JSON keys are always strings, so a dictionary with int keys comes back with string keys after a save and load.

:::predict
```py
import json
data = json.loads('{"ok": true, "score": null, "tags": ["a", "b"]}')
print(data["ok"], data["score"], len(data["tags"]))
```
- true null 2
+ True None 2
- True null 2
- Error
= json converts true to True, null to None, and the array to a list of 2 items.
:::

:::recall
Q: What is the difference between json.load and json.loads?
A: json.load reads JSON from a file object; json.loads reads it from a string.
Q: What does indent=2 do in json.dump?
A: Formats the JSON over several lines with indentation so people can read it.
Q: What do JSON's true, false and null become in Python?
A: True, False and None.
:::

@lesson 12.4 | Project: Study log analyzer | 45 | project
@goal Read a real-looking data file, summarise it, print a report and save the summary as JSON.

You've logged two weeks of study in a CSV file. Time to find out where the hours really went.

```file study_log.csv
date,subject,minutes
2026-10-05,Polity,60
2026-10-05,Maths,45
2026-10-06,History,30
2026-10-06,Polity,40
2026-10-07,Maths,60
2026-10-08,GK,20
2026-10-08,Polity,50
2026-10-09,Python,60
2026-10-10,Maths,30
2026-10-10,Python,45
2026-10-11,History,40
2026-10-11,Python,60
```

Your program prints this report:

```text
Study log: 7 days, 540 minutes (9.0 hours)
By subject:
  Python     165 min
  Polity     150 min
  Maths      135 min
  History     70 min
  GK          20 min
Best day: 2026-10-05 with 105 min
Average per day: 77.1 min
```

and saves `summary.json`:

```text
{
  "total_minutes": 540,
  "by_subject": {"Python": 165, "Polity": 150, "Maths": 135, "History": 70, "GK": 20},
  "best_day": "2026-10-05"
}
```

(With `indent=2` the nested dictionary will spread over more lines; that's fine.)

## Plan

1. Read the CSV with DictReader. For each row, add the minutes to a per-subject total and a per-day total (two dictionaries; `defaultdict(int)` or `.get()`).
2. Total minutes = sum of the subject totals. Hours = minutes / 60, one decimal place.
3. Sort subjects by minutes, highest first. Each line is `f"  {subject:<10}{minutes:>4} min"`.
4. Best day: the day with the most minutes. Average per day: total / number of days, 1 decimal place.
5. Save the summary dictionary with `json.dump(..., indent=2)`. Keep `by_subject` in the same highest-first order.

:::real
This is a real data workflow in miniature: load, aggregate, sort, report, save. The Data & AI track does the same with pandas, which turns most of these steps into one line each, but now you'll know what those lines are doing.
:::

:::recall
Q: What are the usual steps of a small data report?
A: Load the data, aggregate (totals, counts), sort or rank, print the report, save the results.
Q: How do you sort a dictionary's items by value, highest first?
A: `sorted(d.items(), key=lambda kv: kv[1], reverse=True)`.
:::

@exercise 12.4a | Build the analyzer | project
Write the analyzer from the lesson. It must print the report exactly and save `summary.json` with the keys `total_minutes`, `by_subject` (highest first) and `best_day`.

```starter
import csv
import json

by_subject = {}
by_day = {}

```

```solution
import csv
import json

by_subject = {}
by_day = {}
with open("study_log.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        minutes = int(row["minutes"])
        by_subject[row["subject"]] = by_subject.get(row["subject"], 0) + minutes
        by_day[row["date"]] = by_day.get(row["date"], 0) + minutes

total = sum(by_subject.values())
ranked = sorted(by_subject.items(), key=lambda kv: kv[1], reverse=True)
best_day = max(by_day, key=by_day.get)

print(f"Study log: {len(by_day)} days, {total} minutes ({total / 60:.1f} hours)")
print("By subject:")
for subject, minutes in ranked:
    print(f"  {subject:<10}{minutes:>4} min")
print(f"Best day: {best_day} with {by_day[best_day]} min")
print(f"Average per day: {total / len(by_day):.1f} min")

summary = {"total_minutes": total, "by_subject": dict(ranked), "best_day": best_day}
with open("summary.json", "w", encoding="utf-8") as f:
    json.dump(summary, f, indent=2)
```
