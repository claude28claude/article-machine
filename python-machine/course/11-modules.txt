@lesson 11.1 | import, math and random | 20
@goal Import modules in the different ways Python allows, and use the most common tools from `math` and `random`.

Python ships with a huge **standard library**: hundreds of **modules**, each a file of ready-made functions. People say Python comes with "batteries included". To use a module, `import` it:

```py
import math
print(math.sqrt(144))
print(math.pi)
print(math.ceil(4.1), math.floor(4.9))
```

The module name and a dot come first: `math.sqrt`. That's a **namespace**: `math.floor` and a `floor` variable of your own can't clash, because one of them lives inside `math`.

## Three ways to import

```py
import math                    # use as math.sqrt
from math import sqrt, pi      # use as sqrt, pi directly
import statistics as st        # a shorter alias

print(math.gcd(12, 18))
print(sqrt(81), round(pi, 3))
print(st.mean([72, 88, 65]), st.median([72, 88, 65]))
```

Prefer `import math` for clarity, `from ... import ...` for a few names you use a lot, and aliases for long names. Avoid `from math import *`: it dumps every name into your file, and you can no longer tell where things came from.

## Useful math tools

| Tool | Gives |
| --- | --- |
| `math.sqrt(x)` | square root |
| `math.ceil(x)` / `math.floor(x)` | round up / down to a whole number |
| `math.pi` | 3.14159... |
| `math.gcd(a, b)` | greatest common divisor |
| `math.factorial(n)` | n! |

## random

```py
import random
print(random.randint(1, 6))             # a dice roll
print(random.choice(["Polity", "GK", "Maths"]))
topics = ["Polity", "History", "Economy"]
random.shuffle(topics)                  # shuffles the list in place
print(topics)
print(random.sample(range(1, 101), 3))  # 3 different numbers
```

Computers make "random" numbers with a formula. Give it the same starting point, called a **seed**, and you get the same sequence every time, which is very useful for testing:

```py
import random
random.seed(2026)
print(random.randint(1, 100), random.randint(1, 100))
random.seed(2026)
print(random.randint(1, 100), random.randint(1, 100))
```

## Finding your way around

`dir(module)` lists everything in a module and `help(thing)` prints its documentation. The official reference is at [docs.python.org](https://docs.python.org/3/library/); learning to read it is part of becoming a programmer.

:::

:::recall
Q: What is the difference between `import math` and `from math import sqrt`?
A: With `import math` you write `math.sqrt`; with `from math import sqrt` you can write `sqrt` directly.
Q: What does `random.seed(42)` do?

@lesson 11.2 | Dates and times | 25
@goal Create dates, count days between them, add days, and format or read dates as text.

The `datetime` module handles calendar maths that would be painful by hand: month lengths, leap years, weekdays.

```py
from datetime import date

today = date(2026, 10, 18)
exam = date(2027, 1, 15)
print(exam - today)
print((exam - today).days, "days to go")
print(today.year, today.month, today.day)
```

`date.today()` gives the real current date. The examples here use fixed dates so everyone sees the same output.

## Adding days

A `timedelta` is a length of time. Add it to a date:

```py
from datetime import date, timedelta

start = date(2026, 10, 18)
print(start + timedelta(days=100))
print(start + timedelta(weeks=12))
```

100 days from 18 October 2026 is Republic Day 2027.

## Formatting dates

`strftime` ("string from time") turns a date into text using **format codes**:

| Code | Means | Example |
| --- | --- | --- |
| `%d` | day, 2 digits | 26 |
| `%m` | month, 2 digits | 01 |
| `%Y` | year | 2026 |
| `%B` | month name | January |
| `%A` | weekday name | Monday |
| `%b` / `%a` | short month / weekday | Jan / Mon |

```py
from datetime import date

r_day = date(2026, 1, 26)
print(r_day.strftime("%d/%m/%Y"))
print(r_day.strftime("%A, %d %B %Y"))
print(r_day.weekday())   # Monday is 0, Sunday is 6
```

## Reading dates from text

`strptime` ("string parse time") does the reverse, using the same codes to describe the text's layout:

```py
from datetime import datetime

d = datetime.strptime("15-08-1947", "%d-%m-%Y")
print(d.strftime("%A"))
print(d.date())
```

`datetime` objects hold a date **and** a time; `.date()` keeps just the date.

:::predict
```py
from datetime import date, timedelta
d = date(2024, 2, 28) + timedelta(days=1)
print(d)
```
- 2024-03-01
+ 2024-02-29
- 2024-02-28
- Error
= 2024 is a leap year, so the day after 28 February is 29 February. datetime knows the calendar rules.
:::

:::recall
Q: How do you get the number of days between two dates a and b?
A: `(b - a).days`. Subtracting dates gives a timedelta.
Q: What do strftime and strptime do?
A: strftime turns a date into text; strptime reads text into a date. Both use codes like %d, %m, %Y.
Q: How do you get the date 30 days after d?
A: `d + timedelta(days=30)`.
:::

@lesson 11.3 | Smarter collections | 25
@goal Count with `Counter`, group with `defaultdict`, and name the fields of tuples with `namedtuple`.

The `collections` module has upgraded versions of the containers you know, built for jobs that come up constantly.

## Counter: counting made easy

Remember the counting pattern from Unit 7? `Counter` does it in one step:

```py
from collections import Counter

votes = ["Riya", "Dev", "Riya", "Sana", "Riya", "Dev"]
counts = Counter(votes)
print(counts)
print(counts["Riya"], counts["Nobody"])
print(counts.most_common(2))
```

A missing key gives 0 instead of a KeyError. `most_common(n)` returns the top n as (item, count) pairs.

```py
from collections import Counter

text = "the right to equality and the right to freedom"
print(Counter(text.split()).most_common(3))
```

## defaultdict: no more "if key not in"

A `defaultdict` creates a missing key's value automatically the first time you touch it. With `list`, every new key starts as an empty list, so grouping needs no checks:

```py
from collections import defaultdict

cities = ["Agra", "Bhopal", "Ajmer", "Bikaner", "Chennai"]
groups = defaultdict(list)
for city in cities:
    groups[city[0]].append(city)
print(dict(groups))
```

Compare that with the version in lesson 7.3, which needed an `if` for every new letter.

## namedtuple: tuples with field names

```py
from collections import namedtuple

Student = namedtuple("Student", ["name", "marks", "city"])
s = Student("Aman", 157, "Jaipur")
print(s.name, s.marks)
print(s)
```

`s.marks` is far clearer than `s[1]`. In Unit 13 you'll meet classes and dataclasses, which go further.

:::predict
```py
from collections import Counter
c = Counter("mississippi")
print(c.most_common(1), c["z"])
```
- [('s', 4)] 0
+ [('i', 4)] 0
- [('i', 4), ('s', 4)] 0
- [('i', 4)] KeyError
= i and s both appear 4 times; most_common keeps the one met first in the text, which is i. Missing items count as 0.
:::

:::recall
Q: What does `Counter(items).most_common(3)` return?
A: The three most frequent items, as (item, count) pairs, most common first.
Q: Why is `defaultdict(list)` handy for grouping?
A: Every new key starts as an empty list automatically, so you can append without checking.
Q: What does a namedtuple add to a normal tuple?
A: Names for its fields, so you can write s.marks instead of s[1].
:::

@exercise 11.3c | Repeated letters
Write `repeated(word)` that returns a sorted list of the letters appearing more than once, ignoring case. `repeated("Committee")` returns `['e', 'm', 't']`.

```starter
from collections import Counter

def repeated(word):
    pass
```

```solution
from collections import Counter

def repeated(word):
    counts = Counter(word.lower())
    return sorted(letter for letter, n in counts.items() if n > 1)
```

@lesson 11.4 | Your own modules | 20
@goal Split code into your own module files, import from them, and use `if __name__ == "__main__":`.

Any `.py` file is a module. When a program grows, move related functions into their own file and import them, exactly as you import `math`.

This lesson comes with a file called `scoring.py`, already saved in your workspace:

```file scoring.py
"""Scoring helpers for SSC mock tests."""

PLUS = 2
MINUS = 0.5


def cgl_score(correct, wrong):
    return correct * PLUS - wrong * MINUS


def accuracy(correct, wrong):
    attempted = correct + wrong
    if attempted == 0:
        return 0.0
    return round(correct / attempted * 100, 1)


if __name__ == "__main__":
    print("Testing scoring.py")
    print(cgl_score(68, 12))
```

Import it like any module:

```py
import scoring

print(scoring.cgl_score(72, 18))
print(scoring.accuracy(72, 18))
print(scoring.PLUS)
```

```py
from scoring import cgl_score, accuracy

print(cgl_score(60, 25), accuracy(60, 25))
```

## What is `if __name__ == "__main__":` for?

Every module has a variable `__name__`. When a file is **run directly**, Python sets it to `"__main__"`. When the file is **imported**, it's set to the module's name (`"scoring"`). So code under that `if` runs when you run the file itself, and stays quiet when someone imports it. That's why importing `scoring` above didn't print "Testing scoring.py".

```py
print(__name__)
```

You'll see this line at the bottom of almost every real Python script. It lets one file be both a reusable module and a runnable program.

:::note
Here, files live in your browser's memory while the page is open. On your laptop (Unit 15) they're real files in a folder, and `import scoring` finds `scoring.py` sitting next to your program.
:::

:::predict
```py
import scoring
print(scoring.__name__)
```
- __main__
+ scoring
- scoring.py
- None
= When a file is imported, its __name__ is the module name. Only the file you run directly is called __main__.
:::

:::recall
Q: How do you use functions from your own file `tools.py`?
A: Put it next to your program and write `import tools` (then `tools.func()`), or `from tools import func`.
Q: What is `__name__` when a file is run directly?
A: `"__main__"`. When the file is imported, it's the module's name.
Q: Why put test or demo code under `if __name__ == "__main__":`?
A: So it runs when you run the file itself but not when another program imports it.
:::
