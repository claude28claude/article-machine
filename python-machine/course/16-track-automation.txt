## Paths

A `Path` represents a file or folder location. The `/` operator joins parts, and it works on Windows and Mac alike:

```py
from pathlib import Path

folder = Path("downloads")
notes = folder / "todo.txt"
print(notes, notes.exists())
print(notes.name, notes.stem, notes.suffix)
print(notes.read_text(encoding="utf-8"))
```

| Attribute or method | Gives |
| --- | --- |
| `p.name` | `todo.txt` |
| `p.stem` / `p.suffix` | `todo` / `.txt` |
| `p.parent` | the folder containing it |
| `p.exists()`, `p.is_file()`, `p.is_dir()` | True or False |
| `p.read_text()` / `p.write_text(s)` | read or write the whole file |
| `p.iterdir()` | everything directly inside a folder |
| `p.glob("*.pdf")` / `p.rglob("*.pdf")` | matching files here / in all subfolders |
| `p.mkdir(parents=True, exist_ok=True)` | create a folder (no error if it exists) |
| `p.rename(new_path)` | rename or move |

## Looking through a folder

```py
from pathlib import Path

for item in sorted(Path("downloads").iterdir()):
    kind = "folder" if item.is_dir() else item.suffix.lower()
    print(f"{item.name:<22} {kind}")

print([p.name for p in Path("downloads").glob("*.pdf")])
```

## Moving files

```py
from pathlib import Path

folder = Path("downloads")
pdfs = folder / "pdf"
pdfs.mkdir(exist_ok=True)
for p in folder.glob("*.pdf"):
    p.rename(pdfs / p.name)
print(sorted(x.name for x in pdfs.iterdir()))
```

:::warn
Automation that moves or renames files can make a mess at the speed of a computer. On your laptop, always try a script on a **copy** of the folder first, and print what it **would** do before letting it do it (a "dry run").
:::

`shutil` handles the rest: `shutil.copy(src, dst)`, `shutil.move(src, dst)` (also across drives), and `shutil.rmtree(folder)` to delete a whole folder, which deserves extra care.

:::recall
Q: How do you join folder and file names with pathlib?
A: With `/`: `Path("downloads") / "notes.txt"`.
Q: What are a path's stem and suffix?
A: For `notes.txt`, the stem is `notes` and the suffix is `.txt`.
Q: Why do a dry run before an automation that moves files?
A: To see exactly what it would do before it does it, since mistakes happen at computer speed.
:::

@exercise A.1a | Count by type
Write `count_by_type(folder)` that returns a dictionary of file extension (lowercase, without the dot) to how many files have it, with keys sorted alphabetically. Files without an extension count as `"none"`. For this lesson's folder:

```text
{'csv': 1, 'jpg': 2, 'mp3': 1, 'pdf': 2, 'txt': 1}
```

```starter
from pathlib import Path

def count_by_type(folder):
    pass

print(count_by_type("downloads"))
```

```solution
from pathlib import Path

def count_by_type(folder):
    counts = {}
    for p in Path(folder).iterdir():
        if p.is_file():
            ext = p.suffix.lower().lstrip(".") or "none"
            counts[ext] = counts.get(ext, 0) + 1
    return dict(sorted(counts.items()))

print(count_by_type("downloads"))
```

```test

expect('count_by_type("downloads")', {"csv": 1, "jpg": 2, "mp3": 1, "none": 1, "pdf": 2, "txt": 1})
```

:::hints
- Loop over `Path(folder).iterdir()` and skip anything that isn't a file.
- `p.suffix.lower().lstrip(".")` gives `pdf`; an empty suffix means no extension.
- `dict(sorted(counts.items()))` sorts by key.
:::

@exercise A.1b | Tidy the folder
Write `organize(folder)` that moves every file in `folder` into a subfolder named after its lowercase extension (`pdf/`, `jpg/`, ...; files with no extension go to `other/`). Return how many files were moved. Leave existing subfolders alone.

```starter
from pathlib import Path

def organize(folder):
    pass
```

```solution
from pathlib import Path

def organize(folder):
    folder = Path(folder)
    moved = 0
    for p in list(folder.iterdir()):
        if not p.is_file():
            continue
        name = p.suffix.lower().lstrip(".") or "other"
        target = folder / name
        target.mkdir(exist_ok=True)
        p.rename(target / p.name)
        moved += 1
    return moved
```

@exercise A.1c | Rename the photos
Write `rename_photos(folder, prefix)` that renames every `.jpg` file (any capitalisation) in `folder`, in alphabetical order of their current names, to `prefix_001.jpg`, `prefix_002.jpg`, ... and returns the list of new names.

```starter
from pathlib import Path

def rename_photos(folder, prefix):
    pass
```

```solution
from pathlib import Path

def rename_photos(folder, prefix):
    folder = Path(folder)
    photos = sorted(p for p in folder.iterdir() if p.is_file() and p.suffix.lower() == ".jpg")
    new_names = []
    for n, p in enumerate(photos, start=1):
        new_name = f"{prefix}_{n:03d}.jpg"
        p.rename(folder / new_name)
        new_names.append(new_name)
    return new_names
```

```test
reset_files()

check(names == ["trip_001.jpg", "trip_002.jpg"], "Returns the new names in order", f"returned {names}")
from pathlib import Path as _P
left = sorted(p.name for p in _P("downloads").iterdir())
check("trip_001.jpg" in left and "trip_002.jpg" in left and "IMG_0003.JPG" not in left, "The files were really renamed", f"folder now has: {left}")
```

:::hints
- Collect the photos with a filter on `p.suffix.lower() == ".jpg"` and sort them.
- `enumerate(photos, start=1)` numbers them; `f"{prefix}_{n:03d}.jpg"` pads the number to 3 digits.

```file candidates.csv
name,roll,centre,exam_date
```

## Templates

An f-string works when the values are already in variables. When the template lives in a file or a setting, use `str.format` with named fields, or `string.Template`:

```py
template = "Dear {name}, your exam is on {exam_date} at {centre}. Roll number: {roll}."
row = {"name": "Aman Sharma", "exam_date": "14 November 2026", "centre": "Jaipur", "roll": "2026104732"}
print(template.format(**row))
```

`**row` spreads the dictionary into named arguments (Unit 10), so every `{field}` is filled from the matching key.

## A message for every row

```py
import csv

template = "Dear {name}, your exam is on {exam_date} at {centre}. Roll number: {roll}."
with open("candidates.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        print(template.format(**row))
```

## One file per person

```py
import csv
from pathlib import Path

out = Path("letters")
out.mkdir(exist_ok=True)
with open("candidates.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        text = f"To: {row['name']}\nCentre: {row['centre']}\nDate: {row['exam_date']}\n"
        (out / f"{row['roll']}.txt").write_text(text, encoding="utf-8")
print(sorted(p.name for p in out.iterdir()))
```

:::real
On your laptop, the same loop fills Word documents (`pip install python-docx`), Excel sheets (`openpyxl`) or emails (`smtplib` from the standard library, with an app password stored in an environment variable). The pattern never changes: rows in, template, files or messages out.
:::

:::recall
Q: What does `template.format(**row)` do?
A: Fills each `{field}` in the template with the value of the matching key in the dictionary row.
Q: What is the bulk-document pattern?
A: Loop over the rows of a data source, fill a template for each, and write or send the result.
:::

```solution
import csv
from pathlib import Path

TEMPLATE = "Dear {name}, your exam is on {exam_date} at {centre}. Roll number: {roll}."

def write_letters(csv_path, out_folder):
    out = Path(out_folder)
    out.mkdir(parents=True, exist_ok=True)
    count = 0
    with open(csv_path, encoding="utf-8", newline="") as f:
        for row in csv.DictReader(f):
            (out / f"{row['roll']}.txt").write_text(TEMPLATE.format(**row) + "\n", encoding="utf-8")

    return count
```

@exercise A.2c | Merge the monthly reports
The folder `reports` has one CSV per month, all with the same columns. Write `merge_reports(folder, out_path)` that writes a single CSV containing every row, with an extra **first** column `source` holding the file's stem (`aug`, `sep`), files in alphabetical order. Return the number of data rows written.

```file reports/aug.csv

Maths,240
```

```file reports/sep.csv
subject,minutes

GK,120
History,150
```

```starter
import csv
from pathlib import Path

def merge_reports(folder, out_path):
    pass
```

```solution
import csv
from pathlib import Path

def merge_reports(folder, out_path):
    rows = []
    header = None
    for path in sorted(Path(folder).glob("*.csv")):
        with open(path, encoding="utf-8", newline="") as f:
            reader = csv.DictReader(f)
            header = header or reader.fieldnames
            for row in reader:
                rows.append({"source": path.stem, **row})
    with open(out_path, "w", encoding="utf-8", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=["source"] + list(header or []))
        writer.writeheader()
        writer.writerows(rows)
    return len(rows)
```

```test

```

@lesson A.3 | Data from web pages | 25
@goal Understand how programs fetch web pages and APIs, and extract data from HTML with BeautifulSoup.

## Fetching (on your laptop)

The `requests` library downloads pages and talks to APIs. It needs the internet, so this part runs on your laptop:

```py norun
import requests

r = requests.get("https://api.github.com/repos/python/cpython", timeout=10)
print(r.status_code)              # 200 means OK
data = r.json()                   # APIs usually answer in JSON
print(data["stargazers_count"])
```

Prefer an **API** when a site offers one: you get clean JSON, and it's the intended way in. **Scraping** HTML is the fallback, and it comes with rules: read the site's terms and its `robots.txt`, keep requests slow and few, and never collect personal data.

## Parsing HTML

Once you have a page's HTML (from `requests`, or a saved file), **BeautifulSoup** turns it into a searchable tree. This lesson has two saved pages:

```file news.html
<html><body>
<h1>Exam updates</h1>
<div class="item"><h2><a href="/notices/cgl-2026">CGL 2026 tier 1 dates announced</a></h2><p>Posted 12 Oct</p></div>
<div class="item"><h2><a href="/notices/chsl-answer-key">CHSL answer key released</a></h2><p>Posted 9 Oct</p></div>
<div class="item"><h2><a href="https://example.org/syllabus.pdf">New syllabus PDF</a></h2><p>Posted 2 Oct</p></div>
</body></html>
```

```file results.html
<table id="results">
<tr><th>Name</th><th>Roll</th><th>Marks</th></tr>
<tr><td>Aman Sharma</td><td>2026104732</td><td>157</td></tr>
<tr><td>Riya Verma</td><td>2026998812</td><td>171.5</td></tr>
<tr><td>Dev Mehta</td><td>2026551207</td><td>142</td></tr>
</table>
```

```py
from bs4 import BeautifulSoup

with open("news.html", encoding="utf-8") as f:
    soup = BeautifulSoup(f.read(), "html.parser")

print(soup.h1.text)
for h2 in soup.find_all("h2"):
    link = h2.find("a")
    print(link.text, "->", link["href"])
```

| Method | Finds |
| --- | --- |
| `soup.find("tag")` | the first matching element (or None) |
| `soup.find_all("tag")` | every matching element |
| `soup.select("div.item h2")` | elements matching a CSS selector |
| `el.text` / `el.get_text(strip=True)` | the text inside |
| `el["href"]` / `el.get("href")` | an attribute |

## Tables to rows

```py
from bs4 import BeautifulSoup

with open("results.html", encoding="utf-8") as f:
    soup = BeautifulSoup(f.read(), "html.parser")

rows = soup.find("table").find_all("tr")
header = [th.get_text(strip=True) for th in rows[0].find_all("th")]
for tr in rows[1:]:
    cells = [td.get_text(strip=True) for td in tr.find_all("td")]
    print(dict(zip(header, cells)))
```

Links like `/notices/cgl-2026` are **relative**. `urllib.parse.urljoin(base, href)` turns them into full addresses.

:::recall
Q: When should you use an API instead of scraping HTML?
A: Whenever the site offers one: the data is clean JSON and it's the intended way to access it.
Q: What is the difference between find and find_all in BeautifulSoup?
A: find returns the first matching element (or None); find_all returns a list of every match.
Q: How do you turn a relative link into a full URL?
A: `urljoin(page_url, href)` from urllib.parse.
:::

```starter
from bs4 import BeautifulSoup
```

```starter
def table_rows(path):
```
```solution
    with open(path, encoding="utf-8") as f:
```

@lesson A.4 | Bots and schedules | 25
@goal Write the "brain" of a chat bot as a testable function, and run scripts automatically every day.

## A bot is a function

Strip away the messaging app and a bot is a function: text in, reply out. Write and test that function first; connecting it to Telegram or WhatsApp is the easy part.

```py
ARTICLES = {14: "Equality before law", 21: "Protection of life and personal liberty"}

def reply(text):
    parts = text.strip().split()
    if not parts:
        return "Say something!"
    command, args = parts[0].lower(), parts[1:]
    if command == "/article" and len(args) == 1 and args[0].isdigit():
        return ARTICLES.get(int(args[0]), "Not in my notes")
    return "Try /article 21"

for message in ["/article 21", "/article 99", "hello"]:
    print(message, "->", reply(message))
```

## Connecting it to Telegram (on your laptop)

1. In Telegram, message **@BotFather**, send `/newbot`, and follow the steps. It gives you a **token**: treat it like a password.
2. `pip install python-telegram-bot`, and store the token in an environment variable `TELEGRAM_TOKEN`.
3. Wrap your function:

```py norun
import os
from telegram import Update
from telegram.ext import Application, ContextTypes, MessageHandler, filters

from brain import reply   # your tested function, in brain.py


async def on_message(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text(reply(update.message.text))


app = Application.builder().token(os.environ["TELEGRAM_TOKEN"]).build()
app.add_handler(MessageHandler(filters.TEXT, on_message))
app.run_polling()
```

(`async` and `await` let one program wait for many messages at once; you can use them here without knowing the details.)

## Running scripts on a schedule

| System | How |
| --- | --- |
| Windows | **Task Scheduler**: Create Basic Task, choose Daily and a time, action "Start a program": your venv's `python.exe`, with your script's path as the argument |
| Mac / Linux | **cron**: run `crontab -e` and add a line like `30 7 * * * /home/you/project/.venv/bin/python /home/you/project/digest.py` (07:30 every day) |

For a script that must decide "is it time yet?", `datetime` does the maths:

```py
from datetime import datetime, timedelta

now = datetime(2026, 10, 18, 21, 15)
run_at = now.replace(hour=7, minute=30, second=0, microsecond=0)
if run_at <= now:
    run_at += timedelta(days=1)
print("Next run:", run_at)
```

:::recall
Q: Why write a bot's logic as a plain function first?
A: It can be tested instantly with plain strings, before any messaging app is involved.
Q: Where should a bot token or API key be stored?
A: In an environment variable, never in the code.
Q: What does the cron line `30 7 * * *` mean?
A: Run at minute 30 of hour 7 (07:30), every day.
:::

@exercise A.4a | The bot's brain
Write `reply(text)` handling these commands (case-insensitive command word, extra spaces ignored):

- `/start` returns `Welcome! Commands: /score CORRECT WRONG, /article NUMBER`
- `/score 68 12` returns `Score: 130.0` (SSC marking: +2, -0.5)
- `/article 21` returns the heading from `ARTICLES`, or `Not in my notes`
- anything else returns `Commands: /score CORRECT WRONG, /article NUMBER`

Wrong arguments (missing, or not whole numbers) also get the commands line.

```starter
ARTICLES = {
    14: "Equality before law",
    21: "Protection of life and personal liberty",
    32: "Remedies for enforcement of rights conferred by this Part",
}

def reply(text):
    pass
```

```solution
ARTICLES = {
    14: "Equality before law",
    21: "Protection of life and personal liberty",
    32: "Remedies for enforcement of rights conferred by this Part",
}
HELP = "Commands: /score CORRECT WRONG, /article NUMBER"

def reply(text):
    parts = text.strip().split()
    if not parts:
        return HELP
    command, args = parts[0].lower(), parts[1:]
    if command == "/start":
        return "Welcome! " + HELP
    if command == "/score" and len(args) == 2 and all(a.isdigit() for a in args):
        correct, wrong = int(args[0]), int(args[1])
        return f"Score: {correct * 2 - wrong * 0.5}"
    if command == "/article" and len(args) == 1 and args[0].isdigit():
        return ARTICLES.get(int(args[0]), "Not in my notes")
    return HELP
```

```test
need("reply", "function")
H = "Commands: /score CORRECT WRONG, /article NUMBER"
expect('reply("/start")', "Welcome! " + H)
expect('reply("/score 68 12")', "Score: 130.0")
expect('reply("  /SCORE   70  20 ")', "Score: 130.0")
expect('reply("/article 21")', "Protection of life and personal liberty")
expect('reply("/article 999")', "Not in my notes")
expect('reply("/score 68")', H)
expect('reply("/score ten 2")', H)
expect('reply("hello")', H)
expect('reply("")', H)
```

:::hints
- Split the text into words; the first is the command, the rest are its arguments.
- Check the argument count and `isdigit()` before converting with int().
- Keep the help text in one variable so every fallback returns the same line.
:::

@exercise A.4b | Next daily run
Write `next_run(now, hour, minute)` that returns the next `datetime` at that time of day: today if it's still ahead of `now`, otherwise tomorrow. Seconds and microseconds are 0.

```starter
from datetime import datetime, timedelta

def next_run(now, hour, minute):
    pass
```

```solution
from datetime import datetime, timedelta

def next_run(now, hour, minute):
    run_at = now.replace(hour=hour, minute=minute, second=0, microsecond=0)
    if run_at <= now:
        run_at += timedelta(days=1)
    return run_at
```

```test

expect("next_run(datetime(2026, 10, 18, 21, 15), 7, 30)", __import__("datetime").datetime(2026, 10, 19, 7, 30))
expect("next_run(datetime(2026, 12, 31, 23, 0), 7, 30)", __import__("datetime").datetime(2027, 1, 1, 7, 30))
expect("next_run(datetime(2026, 10, 18, 7, 30), 7, 30)", __import__("datetime").datetime(2026, 10, 19, 7, 30))
```

:::hints
- `now.replace(hour=..., minute=..., second=0, microsecond=0)` gives today at that time.
- If that's not after now, add `timedelta(days=1)`. Month and year changes are handled for you.
:::

@lesson A.5 | Project: Daily revision digest | 45 | project
@goal Combine files, dates, sorting and text building into a script you can schedule every morning.

Every morning, a script reads your study log and tells you what you've been neglecting. Here's the log:

```file study_log.csv
date,subject,minutes
2026-10-05,Polity,60
2026-10-08,GK,20
2026-10-11,History,40
2026-10-12,Maths,45
2026-10-14,Polity,50
2026-10-15,Python,60
2026-10-16,Maths,30
2026-10-17,Python,45
```

Write `digest(log_path, subjects, today)` that returns this text for the subjects `["Polity", "History", "Geography", "Maths", "GK", "Python"]` and today = 18 October 2026:

```text
Revision digest for 18 October 2026
1. Geography: never studied
2. GK: 10 days ago
3. History: 7 days ago
Study time in the last 7 days: 230 min
```

and also writes it (plus a final newline) to `digest.txt`.

## The rules

- For each subject, find the **latest** date it appears in the log, ignoring any rows after today. Days ago = today minus that date.
- The 3 most neglected subjects come first: never-studied subjects at the top (in the order they appear in `subjects`), then the highest number of days. Ties keep the order of `subjects`.
- The last line adds up the minutes from the 7 days ending today (today and the 6 days before).
- The date line uses `today.strftime("%d %B %Y")`. Use `"1 day ago"` for exactly one day.

On your laptop, schedule it for 07:00 and send the text to yourself with the Telegram bot from the last lesson.

:::recall
Q: How do you sort so that "never studied" comes before everything else, then by most days?
A: Sort with a key that gives never-studied items the biggest value, for example float("inf") days, and use reverse=True or a negative number.
Q: How do you find the 7 days ending today?
A: Dates d with `today - timedelta(days=6) <= d <= today`.
:::

@exercise A.5a | Build the digest | project
Write `digest(log_path, subjects, today)` as described in the lesson.

```starter
import csv
from datetime import date, timedelta

def digest(log_path, subjects, today):
    pass

print(digest("study_log.csv", ["Polity", "History", "Geography", "Maths", "GK", "Python"], date(2026, 10, 18)))
```

```solution
import csv
from datetime import date, timedelta

def digest(log_path, subjects, today):
    last_seen = {}
    week_minutes = 0
    week_start = today - timedelta(days=6)
    with open(log_path, encoding="utf-8", newline="") as f:
        for row in csv.DictReader(f):
            day = date.fromisoformat(row["date"])
            if day > today:
                continue
            subject = row["subject"]
            if subject not in last_seen or day > last_seen[subject]:
                last_seen[subject] = day
            if week_start <= day <= today:
                week_minutes += int(row["minutes"])

    def neglect(subject):
        if subject not in last_seen:
            return float("inf")
        return (today - last_seen[subject]).days

    ranked = sorted(subjects, key=neglect, reverse=True)[:3]
    lines = [f"Revision digest for {today.strftime('%d %B %Y')}"]
    for n, subject in enumerate(ranked, start=1):
        days = neglect(subject)
        if days == float("inf"):
            lines.append(f"{n}. {subject}: never studied")
        elif days == 1:
            lines.append(f"{n}. {subject}: 1 day ago")
        else:
            lines.append(f"{n}. {subject}: {days} days ago")
    lines.append(f"Study time in the last 7 days: {week_minutes} min")
    text = "\n".join(lines)
    with open("digest.txt", "w", encoding="utf-8") as f:
        f.write(text + "\n")
    return text

print(digest("study_log.csv", ["Polity", "History", "Geography", "Maths", "GK", "Python"], date(2026, 10, 18)))
```


- Build the lines in a list and join with `"\n"`.
:::
